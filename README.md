# TaskDeck

TaskDeck is a compact, reusable skill for turning task lists into a clear, actionable board.

## Purpose

Use it to capture work, group tasks by status or priority, and keep the next action visible without adding unnecessary process.

## Status

The repository is intentionally starting small. Add the skill definition, examples, and any supporting automation here as they are designed.

## Repository hygiene

- Keep credentials, local settings, and generated output out of version control.
- Keep changes focused and document user-visible behavior in this README.
